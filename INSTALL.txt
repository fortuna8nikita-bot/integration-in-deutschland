Brandenburg Helfer

1. Установите Node.js 22.
2. Распакуйте этот архив в пустую папку.
3. В этой папке выполните: npm install
4. Запуск: npm run dev
5. Откройте в браузере адрес, который покажет команда (порт 8080).

Это веб-приложение. Папка node_modules в архиве нет специально: npm install скачает её заново.
